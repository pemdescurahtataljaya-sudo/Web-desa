⚠️ V. Catatan Keamanan Hosting & UU Perlindungan Data Pribadi

⚡ Status Hosting Saat Ini (Shared Hosting cPanel)

Sistem saat ini ditempatkan pada Shared Hosting cPanel. Untuk mengelola informasi publik desa (berita, profil, APBDes, infografis umum, peta), Shared Hosting ini SANGAT MEMADAI & AMAN.

🚨 PERINGATAN WAJIB JIKA DI KEMUDIAN HARI MENAMBAHKAN DATA KEPENDUDUKAN SENSIF

Apabila di masa mendatang akan ditambahkan fitur pengolahan Data Kependudukan Sensitif (seperti NIK, Kartu Keluarga/KK, Data Bansos, DTKS, KTP), maka WAJIB HUKUMNYA DILAKUKAN:


1. Migrasi Metode Hosting: Pindah dari Shared Hosting ke VPS (Virtual Private Server) / Cloud Server (DigitalOcean, AWS, GCP, Biznet, dll) untuk isolasi keamanan penuh.

2. Peningkatan Keamanan: Terapkan enkripsi database AES-256, hashing bcrypt salt ≥12, Rate Limiting, WAF (Cloudflare Pro), Audit Log, dan Kepatuhan UU PDP No. 27 Tahun 2022.
